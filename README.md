# Signal Path

The public website for Signal Path, an independent AV practice based in Boulder, Colorado. The live site is [signalpathpro.com](https://signalpathpro.com/).

## Preview locally

Run `python3 -m http.server 8000` in the repo root, then open `http://localhost:8000/`. No build step is required.

- `index.html` is the home page, including services, experience, process, FAQ, and contact.
- `about.html` introduces James and his approach.
- `css/index.css` styles both pages. Brand assets are in `img/logo/`.
- Leave `CNAME` in place to preserve the custom-domain configuration.

For portfolio additions, get permission before publishing client names, logos, photos, or testimonials. Keep internal routing documents, administrative records, and tax files out of this public repo.
